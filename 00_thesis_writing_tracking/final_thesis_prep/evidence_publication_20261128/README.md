# Appendix F evidence publication — 28 November 2026

This directory publishes the 19 individually cited evidence files that lacked a
verified GitHub file link. The researcher authorized their extraction and
publication, removal of the former E003/E004 sources from the active thesis,
and renumbering of the remaining register to E001–E152.

[manifest.json](manifest.json) records each original source path, exact archive
member or embedded-text key where applicable, byte count, SHA-256 identity,
publication path and former/current evidence ID. Its ID map distinguishes the
removed sources from the different sources that now use E003 and E004.
Historical archives, reports and previously published revisions retain their
original identifiers; no history is rewritten.

The evidence files retain their exact source bytes. In particular, the archived
ViFailback reports are dated historical versions and do not replace later
closure records. The recovered historical CURRENT_RESULTS.json is distinct from
the 24 November final snapshot. The two implementation JSON files are the exact
individually cited map/snapshot files; the full implementation export is not
published by this pass.

Publication checks covered source identity, the cited file structure, and the
absence of raw dataset/media payloads or credentials in the selected contents.
Historical workspace paths and source/record identifiers remain provenance.
Reading and publishing evidence do not reproduce model training, validate every
scientific claim, or resolve missing experiment artifacts.

Exact allow rules restrict this directory to the reviewed files. Git attributes
preserve original line endings. The containing Git commit identifies this
publication revision; Appendix F uses full-commit file permalinks.
