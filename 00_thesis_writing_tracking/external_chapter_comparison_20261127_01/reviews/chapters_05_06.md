## Chapter 5 — PHM

### Changes that should not replace current material

1. **Negative control is a substantive change, not stylistic compression.** [External PHM, line 5](../snapshots/external/05_phm.tex) says, “In retrospect, PHM serves as a methodological negative control.” [Pre-revision PHM, lines 9–10](../snapshots/pre_revision/05_phm.tex) expressly says it was not designed as a negative control with an independently known null effect. [Current PHM, lines 372–380](../snapshots/current/05_phm.tex) retains the actual progression from welding-motivated architecture work to native-outcome studies. The external file itself retains that chronology at line 120. An unsuccessful proxy-prediction comparison does not acquire the design properties of a negative control retrospectively. Use the diagnostic/target-validity description already in the current opening.

2. **The external file loses the fixed-split result entirely.** [Current PHM, lines 280–287](../snapshots/current/05_phm.tex) reports eight EXP-F runs, MAE 0.6548 versus 0.7348, improvement 0.0800 percentage points below the 0.15-point criterion, and the reported model-minus-constant interval `[-0.548,+0.414]`. [External PHM, lines 82–88](../snapshots/external/05_phm.tex) retains the fixed-split protocol but goes directly to LOEO results. This is an actual result omission, not relocation within the external chapter. The retained LOEO table values agree between versions; do not combine the fixed-split result with the twenty-run LOEO comparison.

3. **The new visual diagnostic results disappear.** [Current PHM, lines 180–193](../snapshots/current/05_phm.tex) distinguishes scalar image/run MAE 0.8939/1.3474, multitask image/run MAE 0.7330/1.6273, and detector TP=0, FP=0, FN=9,883 at confidence 0.60 and IoU 0.50. It separately states 30/38 appearance agreement after four unsure exclusions from 42 selected extremes, versus 29/38 for the best of twenty DINOv2 configurations. [External PHM, lines 64–67](../snapshots/external/05_phm.tex) retains qualitative limitations but none of these numerical outcomes. Preserve the v2 versus v3 distinction, 224-image versus eight-run units, threshold-specific detection interpretation, and selected one-reviewer appearance limits.

4. **The evidence attribution becomes less precise.** [Current PHM, lines 228–238](../snapshots/current/05_phm.tex) anchors feature construction to E126 and explains that E027's misleading directory name does not establish a single-encoder run because its command invokes `train_late_fusion.py`. [External PHM, line 75](../snapshots/external/05_phm.tex) cites E027 as the minute-feature configuration without that correction. [Current PHM, lines 270–278](../snapshots/current/05_phm.tex) also records absent historical entry points in the fixed-fusion/LOEO commits, distinguishing saved-score verification and current-source inspection from complete historical lineage. The external paragraph at line 85 retains generic missing-fold-record and stale-target-label cautions, but drops this specific E131/E132 gap. Keep the local corrections.

5. **Ridge and four-arm navigation regresses.** [Current PHM, lines 240–248](../snapshots/current/05_phm.tex) identifies Ridge as a supplementary historical v2 fixed-split result and links to its appendix section. External line 78 restores the alpha search grid but loses that explicit placement. The grid could be retained as a small detail if useful, with the current cohort qualification. [Current PHM, lines 343–354](../snapshots/current/05_phm.tex) names the pre-fold normalizer fitting and points to the separately retained four-arm values. External line 112 returns to “Detailed diagnostic tables belong in Appendix D,” even though the current appendix already contains them. Its external lines 75 and 85 still mention the shared-normalizer issue, so the issue is softened/dispersed rather than wholly removed. Preserve the concrete finding and actual appendix links.

## Chapter 6 — REASSEMBLE

### Preserve the older F2 diagnostic as well as the new additions

1. **The visual-term diagnostic predates November 27 and is not merely a missing new table.** [Current REASSEMBLE, lines 397–418](../snapshots/current/06_reassemble.tex), also present in [pre-revision lines 410–431](../snapshots/pre_revision/06_reassemble.tex), explains the positive sensor coefficients, the reduced-score monotonic transformation and the observed within-fold ordering changes after restoring vision: AUROC improves in all five folds, AP in four, with one AP difference of `-0.00469`. [External lines 103, 110 and 153–154](../snapshots/external/06_reassemble.tex) replace this with the more general missing-control caveat and remove E113 entirely from the chapter. The caveat is valid but is not a substitute for the narrower positive finding. Preserve both. Current Appendix D and Chapter 9 still discuss this diagnostic, so wholesale replacement would also weaken the explanation connecting them.

2. **The full corruption table is missing.** [Current lines 481–511](../snapshots/current/06_reassemble.tex) give all seven strongest operators and both known-absence routes, with the intact reference, F2 AP/Brier/ECE and F5/F6 AP. The known-absence mechanism survives in prose, but its tabulated values disappear. The November 27 [verification record](../../empirical_revision_20261127_01/VERIFICATION.md) reports independent saved-score recomputation for these conditions; this comparison did not repeat that verification. 3. **The permutation method again lacks outcomes.** [Current lines 173–180](../snapshots/current/06_reassemble.tex) states the nineteen-permutation outcomes: vision observed AP 0.2307 versus null 0.1435–0.1784 and PatchTST 0.2416 versus 0.1548–0.1876, each plus-one probability 0.05. [External line 61](../snapshots/external/06_reassemble.tex) retains nineteen permutations and the attainable minimum but omits both outcomes and their restricted interpretation. Keep the outcomes or explicitly relocate them with a reference; simply restoring the external paragraph would reopen the reporting gap.

4. **The follow-up table is lost, while most follow-up evidence survives.** [Current lines 552–583](../snapshots/current/06_reassemble.tex) maps ten comparisons to populations, controls, AP contrasts, intervals and completion limits.
