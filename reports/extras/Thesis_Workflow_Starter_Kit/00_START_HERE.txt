Turn the existing thesis evidence and ten-chapter outline into a complete 80-100-page master's thesis. The working budget is 90 pages of main text. Front matter, references and appendices are separate pending confirmation of the programme rule. The page target is a planning constraint; do not fill pages with unsupported text or repetitive background.

SEARCH METHOD
Pilot six themes: industrial/robotic tasks; representation suitability; comparative fusion; missing/noisy modalities; evaluation validity; adaptation/transfer.
Start with approximately 8-12 candidates per theme as a manageable pilot, allowing overlap. This is not a required citation count and not a claim of completeness.
Include primary research, relevant negative findings and clearly marked preprints. Use surveys for orientation/citation chasing, then read the underlying studies for claims.
Include older foundational papers. Current search cutoff is 14 November 2026; refresh before the final literature freeze.
Record query, date, filters, source, screening decisions and inaccessible papers. Relate alternate paper versions and avoid double counting. Do not call the process systematic unless its actual execution supports that description.
A saturation decision requires relevant theme coverage and a documented follow-up search that adds no materially new approach/contradiction; it is not proof that no unknown work exists.

EVIDENCE PACKET FOR EACH SUBSECTION
Section purpose and research question; intended claim IDs; original source passages and locators; actual citation keys; matching result IDs; author explanations; limitations; planned figures/tables; target length; unresolved evidence.
Draft -> factual/method review -> researcher review -> canonical integration -> compile/render -> handoff.
Different AI chats help separate roles but are not independent human reviewers.

EXPERIMENT BOUNDARIES TO PRESERVE
The baseline reports an accepted move from Intel welding to PHM/REASSEMBLE. Preserve the original four subquestions and distinguish later scope decisions.
PHM targets are derived proxies; principal LOEO and affected four-arm diagnostics stay separate.
REASSEMBLE original five-fold and selected-fold/long-training follow-ups must not be merged.
MSM completed native evaluation supersedes historical smoke-only status, but does not prove trained cross-dataset transfer.
ViFailback completed frozen evidence stays separate from newer matched work whose current status is unverified here.
HANDOVER is supplementary in the current outline; blocked learned fusion cannot be described as an evaluated failure.
Interpretability, deployment, independence and robustness claims require their own evidence.

GAP DECISION
For each candidate gap record closest prior work, what it already solves, the precise remaining dimension, corresponding completed experiments and counterevidence.
Verdicts: plausible; needs narrowing; already addressed; insufficient evidence.
Possible contribution types include comparative evaluation and conditional findings. Do not retrofit an exploratory result into a prespecified hypothesis or relabel an error as an intended contribution.

WRITING AND QUALITY
Use the researcher's explanations and a representative writing sample for voice. Draft original synthesis rather than word-by-word paraphrase. Preserve source attribution and distinguish direct quotation.
Keep numerical checks, literature verification, plagiarism/similarity review and AI-use disclosure as different tasks. No detector outcome is guaranteed.
Document actual prompts, purposes, available tool/model version, input/output versions and checks. Missing historical prompts are missing, not reconstructed.
Add a dedicated AI-use and prompt record at the end/appendix in the required format, along with references. Run an institution-approved similarity check when available and review matches individually; record if it has not run.
Finish a complete evidence-qualified first draft before optional refinements consume the workflow. A finished draft is not the same as a fully approved submission.
