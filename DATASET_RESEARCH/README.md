# Dataset research workspace

This shared entry point groups the dataset studies using relative references. Existing canonical folders, raw data, reports, embedded paths and active jobs are preserved in place.

- [MSM](MSM/README.md): current MSM evaluation.
- [MILLING_DATASET](MILLING_DATASET/README.md): historical acquisition and feasibility evidence for the same MSM dataset; it is not an additional independent dataset.
- [HANDOVER](HANDOVER/README.md): current Handover evaluation.
- [REBOOT](REBOOT/README.md): independent feasibility and visual-failure review.

New REBOOT work lives in the top-level REBOOT folder, with immutable downloaded inputs, versioned runs, manifests, source hashes, alignment evidence, review sheets and an explicit research decision. No existing work was moved or duplicated.
