# MSM examination materials

Open [the full gallery](prediction_examples/index.html). It contains five negative and five positive native examples, 16 real frames each, full-camera/context views, synchronized sensor plots and measured held-out probabilities. Additional deterministic error examples are labeled separately.

The five preserved parameter-matched normal/abnormal pairs were selected before this evaluation. Both laboratory machines are included. Each pair matches eight cutting fields but direction differs (normal DOWN/abnormal UP); these are examination examples, not a direction-controlled causal comparison.

These examples are for researcher review; no frame-level anomaly labels or proof of visual observability is implied.
