## Status meanings

| Status | Meaning |
|---|---|
| SUPPORTED WITHIN SCOPE | Evidence supports the stated restricted proposition; no claim of universality, pristine confirmation or full reproduction. |
| PARTIALLY SUPPORTED | A relevant component/result exists, but the wider interpretation needs qualification. |
| INCONCLUSIVE | The comparison permits materially different conclusions; no equivalence follows. |
| CONTRADICTED WITHIN TESTED PROTOCOL | An implementation fact, observed comparison or specified acceptance decision conflicts with the proposition. This does not prove universal population inferiority. |
| UNTESTED | The material task/intervention/population was not evaluated. |
| UNKNOWN DUE TO INSUFFICIENT EVIDENCE | Available documentation or checks cannot identify the property, even if indirect evidence exists. |
