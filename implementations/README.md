## Review route and guide convention

Use the [thesis-to-code map](../docs/THESIS_CODE_MAP.md) for chapter sections and existing evidence identifiers. Each guide reuses study-local documentation for: dataset motivation and source; modalities/target semantics; preparation; implemented experiments; model/configuration; fitting/evaluation; results; completed, exploratory, unsuccessful or unfinished work; and scientific limitations. The guides need not have identical physical trees. Existing protocols, handoffs and manifests supply detail instead of a second copy of each report.

For data access, follow the dataset's overview/source or recovery records and the official release terms. Native roots and acquisition identities are retained; large raw payloads, checkpoints and feature caches may be local or external. Consult the [publication review](../00_thesis_writing_tracking/consolidation_20261126/) for intended inclusion, exclusions and manual permissions. Historical reproduction commands require renewed task-specific execution authorization.
