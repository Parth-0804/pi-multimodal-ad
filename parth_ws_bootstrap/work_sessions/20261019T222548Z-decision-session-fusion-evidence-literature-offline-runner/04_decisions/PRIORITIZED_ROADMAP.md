## Six ideas and dispositions

1. **Unfreeze the CNN — DEFER new fits; REUSE/VALIDATE history.** Fixed weights differ from limited input visibility. Actual core source freezes the returned backbone and averages16 frames. Later final-stage fine-tuning source exists, but complete V-FT results are not established and Task1 was discontinued. Preserve that disposition. Frozen/partial/full choices and explicitly unapproved settings are in EXPERIMENT_CARDS. Training from scratch is rejected for now because it changes initialization, data/compute needs and question together. Literature P06 supplies counter-evidence to assuming fine-tuning must help.

2. **Use the transformer — REUSE temporal work; DEFER spatial detector representation.** TemporalHead and PatchTST paths already exist; retained core sensor branch is statistics. Detector spatial encoder/query representations are different from attention over frames and are not used by the traced core backbone forward. An extra component needs a hypothesis about information lost by current pooling, plus capacity/order controls. Checkpoint branding is not a hypothesis. Literature P08/P09/P05 distinguishes those mechanisms and their limits.

3. **Research/theory contribution — SCOPING REVIEW DONE; original independent review UNRESOLVED.** Twenty primary study records,16 targeted full texts,4 restricted sources and about 3000 words support conditional reasoning. QMF provides conditional bound analysis, and Willibald et al. already fuse visual-language and force/pose experts by confidence in robot tasks. The plausible contribution is a carefully controlled empirical reliability question with native target/timing and explicit negative conclusions, not “first adaptive multimodal industrial fusion.” No new theorem or proof-of-novelty claim is supported.

4. **Friendly UI — DEFER implementation.** UI_REQUIREMENTS is a textual contract for saved-data/result inspection, actual availability, provenance and evidence labels. Existing replay is a reference for completed-segment predictions, not an implemented live system. UI should expose evidence quality rather than invent missing predictions. It need not wait forever for an external dataset, but implementation needs its own later scope and validated artifact contract.

5. **Noise/robustness — REUSE existing studies; VALIDATE matched coverage.** Section3 already implements the proposed one-modality perturbations. Selected conditional AP arithmetic shows image noise can matter greatly; the hypothesis that the image branch barely matters is not established. F2/gates change both link and adaptivity, whereas anchored constant/adaptive controls exist on clean inputs. Weight motion is not causal attribution. Do not repeat generic noise trials or revive Task4; first establish what comparison is actually absent.

6. **Second dataset / compatibility — PROPOSE metadata feasibility after method question.** The old pair remains UNKNOWN; “milling” is not a recovered identity. Public candidates are new and have material task/modality gaps. Separate datasetB retraining, fixed-weight transfer, interface portability, metric checking, inference repeatability and training reproduction. Preserve native targets; no fabricated binary outcome or image modality. Lock method/selected optional-study dispositions before external assessment. Do not compare unmatched published AP values.

## Exposure and null results

Core and additional outcomes were repeatedly consulted; current numerical checks add exposure to selected banks. Temporal, sensor, anchored and pooling follow-ups are exploratory same-cohort records; choosing published/internal winners does not create an unused final test.
