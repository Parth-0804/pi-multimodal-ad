# Prioritized plan — PROPOSED / NOT APPROVED

Primary question: under a defined completed-action outcome task, does input-dependent fusion improve absolute corrupted-input performance over matched constant/static fusion using identical branch evidence, and under which failures does it not help? This is a proposal, not a novelty or performance claim. See ../02_source/CURRENT_SYSTEM_MAP.md and ../03_history/EXISTING_EXPERIMENTS.md for cited implementation and coverage evidence.

## Smallest sequence

1. User decides the bounded independent literature brief/access budget. Execute only later in a verified results-isolated context; this audit prepares the assignment only. The original dataset pair remains unresolved.
2. Review that synthesis against existing internal coverage. Choose one scientific question and an evidence-validation scope; lock target, sample/split identity, source/runtime/config, selection exposure, matched controls and resource limits. Validate retained baseline evidence only under a separate explicit authorization. Do not begin fresh corruption runs just because the earlier conversational outline proposed them.
3. If an actual missing robustness comparison remains, register the smallest paired study with clean/one-modality-corrupted/known-missing conditions and a matched constant/adaptive mixing rule. Existing clean-trained Section3, anchored controls, dropout and excluded Task4 must be accounted for first. No implicit repeat or extension of Task4.
4. Consider encoder studies only if a distinct representation hypothesis survives. Task1 was discontinued: a new user decision is required before revisiting any partial work. Do not make optional architecture work a prerequisite for a thesis contribution unless scientifically necessary.
5. Freeze the selected method and all baseline/adapter/training-selection rules before approved external assessment. Every selected optional study must have an evidence-backed disposition, including negative results; omitted/deferred studies require an authorized selection decision, not silent cherry-picking.
6. Build an inspection UI later, consuming validated saved outputs and clearly stating prediction timing. Software reproducibility requirements are established earlier; UI work is not required to investigate robustness.

## Candidate 1 — frozen versus fine-tuned visual representation (DEFERRED)

Hypothesis: adapting a predefined final spatial stage changes useful visual evidence and consequently the fusion trade-off; freezing is not presumed to be the cause of past limitations.
Closest internal evidence: frozen core head fitting; final-stage FineTunedVisual/prefix-cache source; gradient-audit metadata; discontinued incomplete Task1 and temporal controls.
Inputs: approved immutable pretrained initialization, precise frames/preprocessing, recording-group splits, selected clean/fault conditions and a source-bound reference representation.
Change isolated: encoder training state in a matched design. Training from scratch is a separate proposal. A temporal-head change and spatial fine-tuning change must not be conflated.
Fixed controls: frames, splits, target, encoder/head capacity where comparable, losses, calibration/threshold provenance, corruption realizations and static/adaptive fusion controls under each representation. Training-only feature-bank rebuilds prevent fitting an encoder outside its partition.
Parameters requiring approval: exact trainable layers, normalization-layer mode, parameter-group rates, optimizer/weight decay, batch/microbatch/accumulation, loss/weighting, augmentation, stopping rule, seed/trial/cost caps. Historical declared rates are not newly selected defaults. No new numeric values chosen here.
Acceptance: verified gradient/cache boundaries and leakage-free partitions; report positive, negative or inconclusive paired outcomes equally. Unsupported or incomplete execution is not a negative scientific result.
Dependencies: literature/gap decision, new disposition of discontinued Task1, baseline/protocol/code-write/compute approval. Allowed future claim: representation effect within tested task/conditions; not universal superiority or a causal freezing diagnosis. Defer/reject if it duplicates partial work without a new question, lacks independent groups, exceeds budget or distracts from fusion adaptivity.

## Candidate 2 — spatial or temporal transformer representation (DEFERRED)

Hypothesis: one specifically chosen spatial or temporal representation offers information beyond a capacity/budget-matched control.
Closest evidence: core visual backbone spatial/temporal pooling; separate PatchTST; later TemporalHead/TEMP/NOPOS and boundary-aware pooling records. Full RT-DETR execution is not required to justify a pretrained checkpoint name.
Inputs: approved frame sequences or sensor sequences with known timing and masks. Change isolated: choose temporal-order/position effect OR detector/spatial encoder features, not both in one comparison.
Controls: same data/preprocessing and training selection; representation capacity/budget reference; positions/order diagnostics where relevant; matched fusion rules if downstream effects are claimed.
Acceptance: source-backed component definition and valid matched comparisons regardless of score direction. Dependencies: coverage/selection audit, distinct hypothesis and budget. Claims limited to tested representation/task, not online detection or general temporal reasoning. Defer/reject if mean-vs-transformer capacity changes cannot be separated, existing work already answers it, or detector components lack a justified role.

## Candidate 3 — independent literature synthesis (FIRST PROPOSED NEXT TASK)

Hypothesis to assess, not assume: relevant literature contains unresolved, falsifiable questions on reliable adaptive multimodal fusion that existing internal studies do not settle.
Closest internal evidence: bootstrap literature brief and this audit coverage map; these project outcomes must be withheld from the literature worker. Inputs: only the results-neutral assignment, approved search/access limits and primary literature/dataset documentation.
Change isolated: an independently constructed evidence synthesis; no architecture selected to rationalize our results. Fixed controls: documented search date/queries/venues, screening criteria, verified primary references, clear theory/empirical/inference labels and limitations.
Acceptance: source-verification ledger, comparison matrix, counter-evidence, at most three feasible falsifiable opportunities; no novelty claim based solely on absence. A finding of no defensible gap is valid.
Dependencies: explicit scope/budget and verified context/file isolation. Exact claims: literature-supported findings with dates and limits; a synthesis is not itself a new theoretical contribution. Defer if isolation/access/budget cannot be established; a nonblind review requires an explicit scope change and label.

Hypothesis/usability objective: a researcher can select dataset/run/sample and correctly interpret saved predictions, conditions and provenance with less manual navigation.

## Candidate 5 — modality robustness and adaptive fusion (PRIMARY SCIENTIFIC CANDIDATE)

Hypothesis: input-dependent fusion helps some degradation conditions relative to matched constant fusion, but may fail under unseen faults or unreliable quality estimates.
Closest evidence: clean-trained Section3 noise/dropout/stuck/missing suites; F4–F6 context ablations; anchored A0/constant/adaptive; modality dropout; excluded Task4 historical results. Therefore a generic noise test is already covered as reported work.
Inputs: approved source-bound branch banks/models, native targets, identical paired assessment samples, train-only scales and validated quality formulas.
Change isolated: input-dependent weights/coefficients versus a constant version of the same output link. Separate clean-trained stress evaluation from corruption-aware training; the excluded Task4 cannot be revived through this task.
Controls: same representation/calibration/threshold, training exposure, capacity/budget accounting, paired fault seeds/severities, absolute performance and degradation, unimodal/competitive static references. Degraded, known absent and undetected failure are separate conditions. Do not feed oracle corruption IDs/severity into ordinary deployment gates.
Acceptance: predeclared valid pairing/targets/scales/quality recomputation and uncertainty by independent group; all prespecified outcomes retained. No AP-gain requirement. Failing validity blocks interpretation; a valid negative result completes the study.
Dependencies: literature and missing-coverage decision, approved protocol/evidence validation and budget. Allowed claims: sensitivity/adaptive utility within the tested fault model, not exact modality-contribution percentages, causal gate explanations or industrial generality. Defer/reject if duplicate, no matched comparison is feasible, data are insufficient, or it overlaps excluded Task4.

## Candidate 6 — external dataset plus portability/reproducibility (CONDITIONAL)

Hypothesis: a locked method can be retrained/evaluated under a second task-compatible dataset protocol, while its software adaptation burden can be measured separately.
Closest evidence: Paderborn and other domain records; no recovered original two-dataset pair and no verified external REASSEMBLE image-sensor fusion comparison.
Inputs: explicitly approved dataset/version/native task/target, synchronized matched modalities, group-aware splits, access/licence and a relevant dataset-specific baseline. No invented proxy target or imagery to force fit.
Change isolated: dataset/task adapter and approved retraining recipe; freeze the core method before final assessment. Controls: fair within-dataset baselines, same labels/splits/selection budget; no comparison of AP across incompatible tasks/protocols.
Acceptance: target/modality compatibility, reproducible provenance and unbiased protocol disposition, including a valid failure to outperform the baseline. Separately measure adapter/shared-core edits, installation declarations, metric reconstruction, inference repeatability and training rerun tolerance/cost.
Dependencies: dataset screening/identity resolution, explicit data/compute permission, METHOD_FREEZE and disposition of every selected optional study. Claims: independent-dataset retraining and measured portability; zero-shot transfer only if weights truly stay fixed and that protocol is separately approved. Defer/reject unsuitable modalities, ambiguous targets, unavailable licence/access, insufficient independent groups or method changes driven by external test outcomes.
