# Historical archive policy

The `archive/` area is reserved for tracked code, configuration, notebooks, and
documentation from superseded research directions.

Archived material remains part of the thesis research history. Archiving is not
deletion, and archived work must retain:

- its original purpose;
- its date and experimental scope;
- known defects and limitations;
- available provenance and links to its replacement.

Archived files must be clearly labelled as historical and must not be presented
as part of the active PHM North America 2026 pipeline.

The archive must not contain:

- raw datasets or copied raw samples;
- generated bulk data, caches, or temporary extraction;
- credentials, cookies, tokens, private keys, session state, or local secrets;
- virtual environments or package caches.

Before any future move, all imports, commands, configuration references,
documentation links, and output provenance must be checked and repaired.
Approved tracked moves should use normal Git-aware moves so file history remains
traceable.

Phase 2 created this policy only. Nothing was archived, moved, renamed, deleted,
or copied into `archive/`. Future archival actions require explicit researcher
approval.
