# PART 3 — DEFINE THE THREE EXPERIMENTAL MODELS

The main scientific question is:

**Does full-backbone fine-tuning improve visual failure prediction and multimodal F2 fusion beyond what can be achieved by longer classifier-only training?**

We require three configurations.

| ID | Model | CNN parameters | Training |
|---|---|---|---|
| A | Original Frozen16 | Frozen | Historical reference |
| B | Long Frozen16 | Frozen | Extended classifier training |
| C | Full FineTuned16 | All executed CNN backbone layers trainable | Extended CNN + classifier training |

## Model A — Historical reference

Use the verified original Frozen16 architecture and its corresponding historical evaluation.

Do not overwrite or silently retrain it.

If exact comparability requires a new evaluation with fixed splits or corrected metrics, report this separately as a reconstructed reference.

## Model B — Extended frozen baseline

- Load the same pretrained CNN initialization.
- Keep the CNN frozen.
- Train the classification head for up to 50 epochs.
- Apply the same 16-frame policy.
- Use training-side validation for checkpoint selection.
- Repeat across the predetermined seeds.

Where possible, reuse fixed visual features efficiently.

Feature caching is valid only if the features and all preprocessing remain identical to the intended frozen-model computation.

## Model C — Fully fine-tuned CNN

- Load the same pretrained CNN initialization.
- Initialize the corresponding classifier head.
- Make the entire executed CNN backbone trainable.
- Train the CNN and classifier jointly.
- Use exactly 16 frames per action.
- Train for up to 50 epochs.
- Repeat across the predetermined seeds.

This means full-backbone **fine-tuning**, not training a CNN from random initialization.

### Full-backbone verification

Before the scientific run, explicitly demonstrate:

1. Early CNN layers have the intended trainable parameters.
2. Middle and final CNN stages are trainable.
3. Nonzero gradients reach the intended backbone parameters.
4. CNN weights actually change after optimizer updates.
5. The classifier receives gradients.
6. No unintended `.detach()` or `no_grad()` blocks CNN training.
7. Unused RT-DETR detector components are not accidentally included.
8. Parameters intended to remain frozen do not change.

Inspect the model's BatchNorm behavior carefully.

The historical benchmark kept the backbone in evaluation mode and its earlier parameters unchanged.

That policy cannot be copied blindly into full-backbone fine-tuning.

Choose and document the appropriate BatchNorm running-statistics and affine-parameter policy before the experiment.

Do not describe a model as fully fine-tuned if substantial executed CNN components remain unintentionally frozen.
